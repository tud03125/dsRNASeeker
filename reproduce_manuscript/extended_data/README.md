# Extended Data S1–S5

S1: Tie-aware precision at k. S2: dsRNAscan binary enrichment. S3: Z22 evidence-direction metrics. S4: FLAG candidate-generation capture. S5: benchmark metrics, uncertainty, orientation, radius, sequence-screened transfer and computing resources.
